User Directory – Data Fetched from a Real API

How this works: Clicking "Fetch Users" sends an HTTP request to jsonplaceholder.typicode.com/users — a free public API. The response (JSON) is parsed and rendered as cards below.
1. User clicks button → 2. fetch() sends GET request → 3. API returns JSON → 4. JS renders cards
🔍 View the fetch code 
// The entire API call — just 6 lines of JavaScript
async function fetchUsers() {
  const response = await fetch(
    'https://jsonplaceholder.typicode.com/users'
  );
  const users = await response.json();   // parse JSON
  renderCards(users);                    // display results
}
