Understanding APIs

Two side-by-side demos that show exactly what changes when you use an API versus hardcoding your data.

NO API

Static / Hardcoded

All data lives inside the HTML/JS file. No network request is ever made.

  • ✗ Data never refreshes automatically
  • ✗ You must edit code to change content
  • ✗ Same result every single time
  • ✓ Works offline, no dependencies
  • ✓ Simple and predictable
View Static Demo →
WITH API

Live / Dynamic

Data is fetched from a real server at runtime using fetch().

  • ✓ Data is always fresh from the server
  • ✓ No code change needed to update content
  • ✓ Can choose how many records to load
  • ✗ Requires internet connection
  • ✗ Must handle errors & loading states

⚡ How an API call works

1

User Action

User clicks a button or the page loads, triggering JavaScript code.

2

HTTP Request

fetch(url) sends a GET request over the internet to an API endpoint.

3

Server Responds

The API server processes the request and sends back a JSON response.

4

Parse & Render

response.json() converts the text into a JS object. The page renders it.

API used in demo: JSONPlaceholder — a free public REST API for testing.
